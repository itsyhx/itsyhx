- 🔧 I build **ESP32-S3 + SSD1306 OLED** projects — from MQTT smart-home hubs to tiny games
- 🏠 Hooking hardware into **Home Assistant** & BLE
- 🐍 Also writing **Python** tooling for dev workflows
- 🌱 Currently exploring: more IoT protocols & display tricks
